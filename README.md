
# WRDLINK

WRDLINK is a Reddit word transformation puzzle game built with Devvit Web. Change one letter at a time using valid four letter English words to reach the target.

## Gameplay

- Start with a four letter word and reach the target word.
- Each move must change exactly one letter.
- Every submitted word must exist in the game's dictionary.
- Reusing words within a chain is not allowed.
- The target must be the final word.
- Invalid moves do not advance the puzzle.

## Scoring

- Each level starts with 50 points.
- Each move deducts one point.
- Points cannot fall below zero.
- Completed level scores accumulate.
- Starting a new game resets the score and level.
