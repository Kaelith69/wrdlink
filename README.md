# WRDLINK

WRDLINK is a Reddit word transformation game built with **Devvit Web**. Change one letter at a time using valid four letter words to reach the target. This Devvit edition carries over the standalone game's campaign scoring, cumulative BFS hints, responsive controls, and motion language while retaining Reddit's inline post launcher and expanded game view.

## How to play

1. Open a WRDLINK post and select **Play puzzle**.
2. Start with the supplied four letter word.
3. Enter a dictionary word that changes exactly one letter from the previous word.
4. Do not repeat a word. The target must be the final word in the chain.
5. Complete the level to earn the reward, then continue the campaign.

## Campaign scoring

- A new campaign starts with **25 points**.
- Every accepted move costs **1 point**, immediately.
- Completing a level awards **25 additional points**.
- The remaining score carries into the next level. It never drops below zero.
- Starting a new game resets the score to 25, level to 1, and campaign hint count to zero.
- Once the score reaches zero, the campaign can continue, but hints are unavailable until enough score is earned from a level completion.

## BFS hints

Hints reveal and automatically submit the next word on a shortest route from the current word to the target.

- First hint price: **5 points**.
- Each subsequent hint costs one more point: **6, 7, 8, 9**, and onward.
- Hint prices are campaign wide and do not reset between levels.
- A confirmed hint pays the hint price plus the normal **1 point move cost**.
- A hint is unavailable when the score cannot cover both deductions or there is no unused route.

## Algorithms

The server owns the authoritative session, move chain, score, and hint count. The client submits one candidate word at a time.

- **Validation:** the server checks word length, dictionary membership, duplicate prevention, one letter difference, and target placement.
- **Neighbor lookup:** candidate words are generated by replacing each letter with A through Z and checking dictionary membership.
- **Shortest route:** breadth first search uses a queue and parent map, then reconstructs the route from the target back to the current word.
- **Puzzle generation:** random walks through legal neighbors create reachable start and target pairs. The shortest distance is stored as puzzle metadata.

## Session persistence

- Devvit's authenticated Reddit user ID is linked to one campaign session in Redis. The browser session ID is used only to adopt an existing legacy session when the account has no campaign mapping.
- Returning in another tab or browser session restores the account linked campaign automatically. The client never supplies or chooses the account identity.
- Redis stores the puzzle, current word chain, score, level, completion state, and campaign hint count. Session mutations are serialized with a short Redis lease to prevent concurrent moves from overwriting each other.
- Both the campaign and its account mapping expire after **7 days** without activity. Each successful session interaction refreshes both expirations.
- Authenticated requests are checked against the account's linked session and rate limited by account. Logged out play retains browser session behavior.

## Reddit and Devvit compatibility

The inline post launcher continues to use Devvit's expanded mode flow. The expanded React game communicates with the Hono API routes. This Reddit edition is gameplay only: it intentionally has no challenge sharing, result cards, social sharing, replay links, file downloads, or PWA installation flow.
